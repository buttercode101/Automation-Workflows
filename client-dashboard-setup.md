# Client Dashboard Setup

## Objective
Create a lightweight dashboard in the same Google Sheet as `Leads`.

## Steps
1. Open Extensions -> Apps Script in the Leads sheet.
2. Paste `google-apps-script-template.js`.
3. Run `bootstrapDashboard()` once.
4. Confirm Dashboard tab appears with 5 KPIs.

## KPI cards
- New leads today
- Contact rate
- Hot lead rate
- Won rate
- Avg lead score
